Як підключити вашу базу Supabase:

  1. Створіть безкоштовний проєкт на supabase.com.
  2. Скопіюйте вміст файлу schema.sql і запустіть його в SQL Editor на сайті Supabase (це створить таблицю та сховище для фото).
  3. Вставте ваш SUPABASE_URL та SUPABASE_ANON_KEY у файл config.js.

Зараз панель працює в локальному демо-режимі. Ви можете додавати і видаляти рослини для тестування прямо в цьому браузері.
