# 🌿 Botanica — Мінімалістичний сайт-вітрина для продажу декоративних рослин (Чигирин)

Естетичний, легкий сайт-вітрина для продажу кімнатних та декоративних рослин із підключенням до хмарної бази даних **Supabase** та оформленням замовлень напряму в **Telegram**.

Створено на чистому **HTML5, CSS3 та Vanilla JavaScript** (без жодних збірок типу Webpack чи Vite, без Node.js) — сайт готовий до миттєвого відкриття у браузері та безкоштовного завантаження на **GitHub Pages**.

---

## ✨ Особливості та Дизайн

* **Мінімалізм та «повітряна» естетика:**
  * Теплий молочно-кремовий фон (`#FAF9F6`)
  * М'які білі картки (`#FFFFFF`) з делікатними тінями
  * Глибокий темно-графітовий текст (`#2C302E`)
  * Приглушений шавлієво-зелений акцент (`#4A6B53`)
* **Вишукана типографіка:** заголовки шрифтом із засічками **Cormorant Garamond**, чистий гротеск **Plus Jakarta Sans** для описів і цін.
* **Вертикальні картки рослин (4:5):** плавний зум фотографій при наведенні курсора, закруглені кути (`12px`), ціновий бейдж.
* **Швидке замовлення в Telegram:**
  * Клієнт натискає «Замовити»
  * Відкривається вікно з готовим текстом (наприклад: *«Добрий день! Хочу замовити рослину: Монстера Деліціоза...»*)
  * Клієнт натискає «Надіслати у Telegram» і одразу потрапляє у ваш діалог в додатку Telegram.
* **Зручна панель адміністратора (`admin.html`):**
  * Захист паролем (змінюється у `config.js`)
  * Завантаження фото рослини з комп'ютера чи смартфона (з попереднім переглядом)
  * Назва, ціна, детальний опис умов догляду та розміру
  * Видалення проданих рослин в один клік (з автоматичним видаленням файлу зі сховища Supabase Storage).
* **Готовий демонстраційний режим:** сайт одразу показує красиві зразки рослин і повністю працює навіть до того, як ви зареєструєтесь у Supabase!

## 🚀 Швидкий старт за 3 кроки

### Крок 1. Створення безкоштовного проєкту в Supabase

1. Зареєструйтесь на сайті [Supabase.com](https://supabase.com) (можна через GitHub).
2. Натисніть **«New Project»**, оберіть назву (наприклад, `botanica-plants`) та задайте пароль до бази.

### Крок 2. Виконання SQL-скрипта (налаштування бази та сховища)

1. У панелі вашого проєкту Supabase зліва перейдіть у вкладку **«SQL Editor»**.
2. Натисніть **«New query»**.
3. Відкрийте файл [`schema.sql`](schema.sql) з цієї папки, скопіюйте весь його текст, вставте в поле SQL Editor та натисніть зелену кнопку **«Run»**.

> **Що робить цей скрипт?**
> * Створює таблицю `plants` для збереження назв, цін, описів та посилань на фото.
> * Вмикає Row Level Security (RLS) з безпечним публічним доступом на читання, додавання та видалення.
> * Автоматично створює публічний бакет `plant-photos` у Supabase Storage для зберігання фотографій.

### Крок 3. Налаштування файлу `config.js`

1. У Supabase відкрийте **Project Settings** (значок шестерні внизу ліворуч) -> вкладка **API**.
2. Скопіюйте:
   * **Project URL**
   * **Project API keys -> `anon` `public`**
3. Відкрийте файл `config.js` у вашому редакторі коду та заповніть параметри:

```javascript
const CONFIG = {
  // Вставте сюди ваші дані з Supabase
  SUPABASE_URL: 'https://ваш-проект.supabase.co',
  SUPABASE_ANON_KEY: 'ваш-довгий-anon-ключ',

  PLANTS_TABLE: 'plants',
  STORAGE_BUCKET: 'plant-photos',

  // Ваш нік у Telegram (без знака @) для отримання замовлень
  TELEGRAM_USERNAME: 'chigirin_botanica',

  // Пароль для входу в адмінку admin.html
  ADMIN_PASSWORD: 'ваш_секретний_пароль',

  SITE_NAME: 'Botanica',
  SITE_SUBTITLE: 'Колекція декоративних та кімнатних рослин • Чигирин',
  LOCATION: 'м. Чигирин, Черкаська обл.',
  CURRENCY: 'грн'
};
```

Готово! Тепер при відкритті `index.html` або `admin.html` сайт підключений до вашої реальної хмари Supabase.

## 🔐 Вхід до панелі керування

1. Відкрийте у браузері сторінку `admin.html` (або натисніть кнопку «Вхід» / «Панель адміністратора» на головній).
2. За замовчуванням пароль: `admin` (ви можете змінити його в будь-який момент у файлі `config.js` у параметрі `ADMIN_PASSWORD`).
3. Після входу ви можете:
   * Вибрати будь-яку фотографію рослини (підтримується також вибір прямо з камери смартфона).
   * Вказати назву, ціну в гривнях та поради щодо догляду/розміру.
   * Натиснути **«Опублікувати на сайті»**. Фото автоматично завантажиться у хмару Supabase Storage, а запис з'явиться на головній сторінці.
   * Для видалення проданої позиції натисніть червону кнопку **«Видалити»** навпроти потрібної рослини у списку праворуч.

## 🌐 Як опублікувати сайт на GitHub Pages (безкоштовний хостинг)

1. Створіть новий публічний репозиторій на [GitHub.com](https://github.com) (наприклад, `botanica-plants`).
2. Завантажте всі файли цього проєкту в кореневу папку репозиторію.
3. Перейдіть у вкладку **Settings** репозиторію -> розділ **Pages** (ліворуч).
4. У пункті **Build and deployment -> Branch** виберіть гілку `main` (або `master`) та папку `/ (root)`, після чого натисніть **Save**.
5. Зачекайте 1 хвилину — GitHub надасть вам безкоштовне посилання виду `https://ваш-нік.github.io/botanica-plants/`.
6. Сайт готовий приймати замовлення з будь-якого пристрою 24/7!
